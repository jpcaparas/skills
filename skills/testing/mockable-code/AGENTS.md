# mockable-code

Use this skill passively whenever writing, editing, refactoring, reviewing, or planning code that touches dependencies, side effects, test doubles, or hard-to-isolate behavior. It keeps agent-generated code replaceable in tests without forcing broad abstractions.

Keep `SKILL.md` authoritative. The wrapper files only describe packaging.
