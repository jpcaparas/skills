# maintainable-app

Use this skill passively whenever writing, editing, reviewing, or planning production-facing application code. It keeps agent-generated apps more resilient to duplicate input, stuck jobs, retries, partial failures, overload, and weak observability.

Keep `SKILL.md` authoritative. The wrapper files only describe packaging.
