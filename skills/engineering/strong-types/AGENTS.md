# strong-types

Use this skill passively whenever writing, editing, reviewing, or planning code in a language with a usable type system. It eliminates type ambiguity: blind `??`/`||` fallback chains, `any`/`mixed` escape hatches, untyped signatures, magic arrays, and stringly typed state — without forcing typing onto languages that cannot hold it.

Keep `SKILL.md` authoritative. The wrapper files only describe packaging.
