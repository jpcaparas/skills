# Source description

The AeroLab controller, which technicians install in the forward equipment bay, continuously monitors pressure from three sensors and it also records temperature values for analysis that is completed later by the maintenance team. It is connected to the bleed valve. The valve is opened by AeroLab. It sends a signal. It records faults. It supplies status. It stores the last result. It stops when the supply voltage is less than 18 V.

The manufacturer and agent are known: AeroLab installs and operates the controller. `18 V` is an exact limit.
