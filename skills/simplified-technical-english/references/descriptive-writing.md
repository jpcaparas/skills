# Descriptive writing

Use this reference for system descriptions, component explanations, theory of operation, reports, brochures, papers, and informational notes.

## Description contract

Descriptive text gives information. It does not command the reader.

Classify each paragraph by one topic, such as:

- identity or purpose
- location or composition
- function
- operation
- state or condition
- cause and effect
- limitation
- result

Do not combine unrelated topics to reduce length.

## Order information progressively

Give the reader the general frame before details that depend on it.

A common order is:

1. identify the item or topic
2. state its purpose or primary function
3. describe its parts or relationships
4. explain operation or sequence
5. give limitations, exceptions, or consequences

Use a different order when the reader’s task requires it. Preserve the source’s causal and chronological relationships.

## Sentences

For each descriptive sentence:

- keep one principal information relationship
- use no more than 25 words under the official Issue 9 counting rules
- use active voice when the agent is known
- use passive voice only when the agent is unknown and the passive construction is necessary
- make the subject and verb explicit
- avoid contractions and omitted words
- use verified connectors to show time, cause, contrast, condition, or result
- do not convert information into an imperative instruction

Source:

```text
The controller, which is installed in the forward bay and is connected to three sensors, continuously monitors pressure and temperature while also recording faults for later analysis.
```

Candidate structural rewrite:

```text
The controller is in the forward bay.
It receives data from three sensors.
The controller monitors pressure and temperature.
It records fault data for subsequent analysis.
```

The final vocabulary and pronoun use require Issue 9 and terminology verification.

## Voice

Prefer:

```text
The control unit sends the signal to the actuator.
```

When the source does not identify the agent and inventing one would change meaning, a descriptive passive can be appropriate:

```text
The signal is recorded.
```

Do not add an actor merely to remove passive voice. Do not use passive voice to hide a known actor.

## Paragraphs

Use paragraphs to show related information.

Each paragraph must:

- contain one topic
- begin with enough orientation for the reader to identify that topic
- contain no more than six sentences
- keep supporting facts close to the statement they explain
- avoid restating the same fact with different terminology

Use a vertical list when several peer items, conditions, or results would make the paragraph difficult to scan. A list does not remove the need for explicit logic.

## Key words and phrases

Use verified connecting words and phrases to show:

- order
- time
- condition
- cause
- result
- contrast
- addition

Do not use a connector merely to make prose smoother. It must express the source relationship exactly.

## Description verification

Compare the result with the source:

- general-to-specific order is useful and faithful
- each sentence has one principal relationship
- each sentence is within 25 words under official counting rules
- each paragraph has one topic and no more than six sentences
- active voice is used when the agent is known
- any passive voice has an unknown agent
- no command was invented
- cause, condition, uncertainty, and consequence are unchanged
- technical terms and protected literals are unchanged or governed
