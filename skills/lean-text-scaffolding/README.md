# lean-text-scaffolding

Installable skill for keeping newly scaffolded web pages concise, specific, and free of filler labels or placeholder copy unless the user explicitly asks for them.

## What it covers

- lean default copy budgets for page scaffolds
- removal of generic eyebrows, badges, filler cards, and unsupported social proof
- preservation of form labels, accessible names, helper text, and error instructions
- a deterministic TSX/HTML audit script for common bloat patterns

## Key files

- `SKILL.md` - authoritative instructions
- `references/rules.md` - detailed keep/cut rules and copy budgets
- `references/research.md` - source-backed rationale and accessibility boundary
- `scripts/audit_lean_text.ts` - optional Bun-powered source audit
