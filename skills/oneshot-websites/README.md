# Oneshot Websites

Production skill for generating semi-deterministic catalogs of parallel one-shot website variants.

## What It Adds

- A full repertoire of single-file website styles
- Harness-neutral parallel generation instructions
- `PROMPT.md` exposure for every generated route
- A benchmark-style directory index with fairness notes
- Validation scripts for generated catalogs

## Key Files

- `SKILL.md` - authoritative instructions
- `references/repertoire.md` - style repertoire and slugs
- `references/generation-protocol.md` - parallel harness contract
- `references/catalog-index.md` - directory index requirements
- `scripts/validate_catalog.py` - generated catalog checker
