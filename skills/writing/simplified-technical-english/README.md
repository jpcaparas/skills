# Simplified Technical English

Production skill for rewriting or auditing selected technical procedures, descriptions, and safety instructions without changing technical meaning or protected literals. Issue 9 is the bundled ASD-STE100 baseline; verification follows the user's governing issue and available authoritative material.

## What it covers

- reference-backed and clearly labelled Issue 9-oriented rewrites
- separate workflows for procedures, descriptions, notes, and safety instructions
- controlled terminology decisions using the official dictionary and governed project terminology
- preservation of conditions, negation, thresholds, sequence, identifiers, code, and mandated wording
- bounded audit reports that separate confirmed findings from unresolved technical decisions
- an optional Python scanner for measurable surface candidates
- release-grade behavioral, disclosure, edge, and trigger evals

`SKILL.md` is the canonical instruction file. References carry branch-specific depth; scripts provide optional diagnostics and package validation.

This package is an independent writing aid. It does not contain the ASD-STE100 standard or dictionary and does not provide ASD certification, endorsement, or approval.
