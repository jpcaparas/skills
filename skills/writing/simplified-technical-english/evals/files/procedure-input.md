# Source procedure

1. Prior to initiating the functional test, ensure that the bleed valve BAV-44 is powered down and disconnected from connector J12.
2. The TorqueCheck routine should then be run and the result should be recorded in test record TR-908.
3. Don't remove the lock pin until pressure is less than 25 psi, and then inspect the bleed valve for external damage.

The required execution order is 1, 2, 3. `BAV-44`, `J12`, `TorqueCheck`, `TR-908`, and `25 psi` are exact literals.
