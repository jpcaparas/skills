# Repository README Writer

Production skill for creating and improving concise repository READMEs with strong quickstarts, stable project orientation, and agent-safe guidance.

## What It Covers

- new README drafting from repository evidence
- existing README rewrites and simplification
- quickstart design and command selection
- high-level project shape without brittle path tours
- version guidance that defers to repository toolchain sources
- README review packets with verification notes

## Key Files

- `SKILL.md` for the authoritative instructions
- `references/foundations.md` for section standards and writing principles
- `references/repository-audit.md` for inspection workflow
- `references/quickstart-design.md` for quickstart design
- `references/rewrite-patterns.md` for existing README improvements
- `scripts/repo_readme_probe.py` for a first-pass repository signal inventory
