# Repository README Writer

This wrapper exists for repository presentation. The authoritative instructions live in `SKILL.md`.

Read `SKILL.md` first, then load only the file that matches the task:

- `references/foundations.md` for README philosophy, section rules, and style
- `references/repository-audit.md` for repository inspection and evidence ranking
- `references/quickstart-design.md` for quickstart structure and command selection
- `references/rewrite-patterns.md` for improving an existing README
- `references/gotchas.md` for common failure modes
