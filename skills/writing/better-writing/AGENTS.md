# better-writing

Canonical behaviour lives in `SKILL.md`.

Use this general-purpose skill to draft, rewrite, line edit, review, humanise, or adapt prose while preserving source truth, exact literals, uncertainty, and writer identity. For technical documentation and wiki entries, apply local style and locale first, then use the reader-first documentation reference. Remove or rebuild canned phrase families from supported meaning; never apply a raw-token ban to precise, technical, literal, quoted, or writer-owned language. Treat scanner matches as revision prompts, never evidence of authorship.
