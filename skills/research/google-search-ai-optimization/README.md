# Google Search AI Optimization

Installable skill for implementing Google-grounded SEO/GEO improvements in web development work, especially for Google Search generative AI features such as AI Overviews and AI Mode.

## What It Covers

- Google Search generative AI guidance without unsupported AI-search hacks
- crawlability, indexability, rendering, canonicals, snippets, and structured data
- non-commodity content, entity clarity, media, and internal-link patterns
- ecommerce, local business, Merchant Center, Business Profile, and agentic UX readiness
- deterministic static page checks with `scripts/audit_page.py`

## Key Files

- `SKILL.md` for the authoritative instructions
- `references/google-guidance.md` for the official guidance baseline
- `references/technical-implementation.md` for web implementation details
- `references/content-and-entity-patterns.md` for content and entity work
- `references/ecommerce-local-agentic.md` for commerce, local, and browser-agent readiness
- `references/gotchas.md` for myths and policy traps
- `templates/implementation-brief-template.md` for implementation handoff
