# reading-notes

Installable skill for turning resources into reviewable notes, research leads, and concrete homework todos.

`reading-notes` works with pasted notes, documents, webpages, YouTube videos, transcripts, screenshots, talks, and other supplied resources. Canonical behavior lives in `SKILL.md`; reference files cover intake, synthesis, output formats, and common failure modes.

## Key files

- `SKILL.md` - authoritative instructions
- `references/intake.md` - resource access and normalization guidance
- `references/synthesis.md` - topic, idea, research, and todo extraction method
- `references/output-formats.md` - Markdown, DOCX, PDF, CSV, XLSX, and JSON export guidance
- `templates/reading-notes.md` - reusable Markdown note skeleton
- `scripts/probe_reading_notes.py` - deterministic source classifier and checklist helper
