This wrapper exists for repository presentation. The authoritative agent instructions live in `SKILL.md`.

Read `SKILL.md` first. Load `references/curation.md` before changing ownership or lifecycle in a skill library. When placement is ambiguous, load `references/placement.md` or run `scripts/infer_destination.py` before scaffolding a new skill. Verify placement changes with `scripts/test_infer_destination.py`.
