# Collision Policy

The universal scaffold is safe only if old managed hook commands are removed before new shared adapters are added.

## Managed Config Entries

The script strips command hooks that reference these legacy roots:

- `.claude/hooks/generated`
- `.codex/hooks/generated`
- `.devin/hooks/generated`

It does not strip prompt hooks, HTTP hooks, MCP hooks, agent hooks, or custom command hooks outside those roots.

## Shared Scripts

`hooks/<event>/script.sh` is generated once per qualifying event and not rewritten by shell harnesses during universal runs, so a deliberate edit survives. It is deleted only when its event stops qualifying, no other harness adapter remains, and its code is still the generated runner.

Harness adapters are disposable. They exist only for events the plan gives behaviour, and a refresh deletes the adapter of any event that no longer qualifies:

- `hooks/<event>/claude.sh`
- `hooks/<event>/claude.json`
- `hooks/<event>/codex.sh`
- `hooks/<event>/codex.json`
- `hooks/<event>/devin.sh`
- `hooks/<event>/devin.json`

## Legacy Folder Cleanup

The script removes old generated folders only when they contain `manifest.json`. That guards against deleting user-owned files that happen to live under a similarly named path.

## OpenCode

OpenCode gets one generated plugin, `.opencode/plugins/scaffold-hooks.ts`, which a refresh rewrites; the scaffold refuses to overwrite a file there that lacks the `Generated by scaffold-hooks` first line. Output of the earlier `opencode-froggy` scaffold is removed only when `.opencode/hook/.managed/manifest.json` proves it: the block between the `scaffold-hooks managed opencode-froggy` markers in `hooks.md`, and the exact `opencode-froggy` entry in `opencode.json`. Old `.opencode/plugins/` output is removed only when `.opencode/plugins/.managed/manifest.json` proves ownership; unmanaged plugin files are preserved.

## Final Verification

After scaffolding, the script scans final harness configs and fails if any selected shell harness still references a legacy generated root.
