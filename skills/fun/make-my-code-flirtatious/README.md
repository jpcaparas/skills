# make-my-code-flirtatious

Fun installable skill for explaining code in a playful, sensual, flirtatious voice without letting the style obscure what the code actually does.

## Install

```bash
npx skills add jpcaparas/skills --skill make-my-code-flirtatious
```

## What It Adds

- explicit-only activation for flirtatious code explanations
- three non-graphic intensity levels: wink, velvet, and sultry
- a factual-spine pass before any metaphor or innuendo
- preservation of exact identifiers, control flow, side effects, and uncertainty
- safety boundaries that keep the flirtation aimed at code rather than people

`SKILL.md` is the canonical behavior contract. The evals cover technical fidelity, tone calibration, invocation precision, high-stakes restraint, and non-explicit boundaries.
