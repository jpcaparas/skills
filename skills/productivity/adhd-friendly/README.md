# adhd-friendly

Portable Agent Skill for low-friction, ADHD-friendly communication and task support. It helps an agent make answers easier to start, scan, resume, and complete without assuming that every person with ADHD needs the same format.

`SKILL.md` is the canonical runbook. The package also includes:

- behavioral and trigger evals for planning, implementation, explanation, re-entry, safety, and near-miss routing
- research notes that separate cognitive-accessibility guidance from clinical evidence and practical inference
- local validators for the package contract
