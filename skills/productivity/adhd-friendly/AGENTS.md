# adhd-friendly

Canonical behavior lives in `SKILL.md`.

Use this skill when a user asks for ADHD-friendly, action-first, low-overwhelm, easy-to-resume communication or task support. It adapts structure and handoff while preserving the task's completeness, safety, evidence, and the user's preferred depth.

Do not trigger it merely because a request discusses ADHD, diagnosis, treatment, dopamine, or general accessibility.
