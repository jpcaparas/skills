# devils-advocate

Actively invoked Agent Skill for stress-testing an idea from the strongest honest opposing position.

## Install

```bash
npx skills add jpcaparas/skills --skill devils-advocate
```

## What It Adds

- explicit-only invocation rather than unsolicited contrarianism
- a steelman-first grill, live debate, opposition brief, and side-switching modes
- material objections tied to mechanisms, consequences, and falsifiers
- honest concessions when a rebuttal succeeds
- respectful guardrails that challenge the idea rather than the person

`SKILL.md` is the canonical behavior contract. The evals and local validators cover debate quality, invocation precision, evidence handling, safety, and stopping behavior.
