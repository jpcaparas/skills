# ElevenLabs Media

An installable skill for ElevenLabs speech, transcription, dubbing, sound effects, music, images and video. Assumes `ELEVENLABS_API_KEY` is already set; individual features still require the appropriate permissions and subscription.

Install with `npx skills add jpcaparas/skills --skill elevenlabs-media`.

Start with [SKILL.md](SKILL.md), the canonical instructions. It routes to task-specific references, a dependency-free Python HTTP helper and reproducible offline checks. See [evidence](references/evidence.md) for the distinction between documented capabilities and executed live spikes.
